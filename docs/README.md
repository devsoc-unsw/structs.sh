# Welcome to Structs.sh Documentation

- Install [uv](https://docs.astral.sh/uv/getting-started/installation/)
- Run `uv run mkdocs serve`, and visit the URL from the command output. An example is shown below

    ```bash
    › uv run mkdocs serve
    INFO    -  Building documentation...
    INFO    -  Cleaning site directory
    INFO    -  Documentation built in 0.03 seconds
    INFO    -  [11:38:24] Watching paths for changes: 'docs', 'mkdocs.yml'
    INFO    -  [11:38:24] Serving on http://127.0.0.1:8000/
    ```
